# Матрица требований Freedom Quality

Источник обязательных требований текущей работы: пользовательское задание. Исходные PDF ТЗ/Student Guide не найдены; docs/критерии_оценки.md — пересказ со ссылкой на них. docs/demo_design.md отсутствует. product_research.md содержит предложения и roadmap, которые не считаются автоматически обязательными. В нём § интеграций называет встраивание Dynamics требованием ТЗ, но первоисточник не подтверждён.
